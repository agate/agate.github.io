# honghao.me

Personal site: projects and thoughts, in English and Chinese. Built with [Astro](https://astro.build), deployed to GitHub Pages on every push to `main`.

## Develop

```sh
npm install
npm run dev      # http://localhost:4321
npm run build    # static output in dist/
```

## Add a thought

Create a folder per post with one file per language (either one is enough):

```
src/content/thoughts/<slug>/en.md
src/content/thoughts/<slug>/zh.md
```

```md
---
title: My post
date: 2026-10-16
draft: false
---

Body in Markdown.
```

Drafts show in `npm run dev` but not in the built site.

## Add a project

Add an entry to `src/data/projects.ts`. Icons are isometric line drawings generated by `scripts/gen_icons.py`:

```sh
python3 scripts/gen_icons.py   # writes src/icons/*.svg
```

## Language

Every visible string is written twice, `<span lang="en">` and `<span lang="zh">`. The `EN / 中` toggle sets `data-lang` on `<html>` and CSS hides the other language. The choice is saved in `localStorage`; `?lang=zh` or `?lang=en` in a URL overrides it.

## Fonts

Set in `src/styles/global.css` (`--en-head`, `--en-body`, `--zh-head`, `--zh-body`) and loaded from Google Fonts in `src/layouts/Base.astro`.
